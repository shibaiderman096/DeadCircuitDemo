## 游戏概览

《废土回路》是一款俯视角2D生存、探索、建造与自动化合作游戏。玩家在程序生成的废土中寻找资源、维持食物和饮水、抵御敌人，并从手工加工逐步发展到机械、电气、化工、精密制造与核工业。

主要循环是：探索与采集 → 加工样品和建造设施 → 研究新工艺 → 连通能源与物流 → 扩大补给和防线 → 向新的资源区域探索。

工业时代和研究成果由整个世界共享；人物等级、属性、专精、随身物资和装备分别归各个角色。个人等级不会替全队解锁工厂，也不需要每位队员重复研究同一项工业技术。

## 快速开局

1. 在开始菜单选择“角色外观”并保存预设，再新建世界。外观在进入世界前设置，游戏内背包中的人物预览用于显示当前穿戴。
2. 当前为自然开局，没有固定出生坐标或教程工作台、石炉、空箱。新角色背包有木材12、废料4、普通食物6；生存补给另有净水2、浆果3及八种作物种子各2。重连和复活不会重复发放。
3. 自行建造工作台，成本木材6。徒手采集木材、石材、黏土和铁矿，再准备石炉，成本木材6、铁矿3；为研究和工具预留额外材料。基础采集允许徒手进行，工具提高效率，原油另需抽油设备。
4. 靠近工作台研究“石制工具”，研究样品为木材2、石材2。当前石斧制作需要木材3、石材2，石镐需要木材3、石材3；石器维修也使用木材和石材。研究样品与制作投入分别按界面提示准备。
5. 按科技树依次发展木炭、陶砖、铜锡和青铜，再研究块炼铁。基础建造可从石制工具节点并行研究。
6. 打开生存手册，准备食物、净水和庇护。烹饪净水属于可选生存研究，但长期探索仍需要稳定补给。
7. 研究水力前，实际生产所要求的材料。仅把回收金属放进背包不等于已经完成生产进度。
8. 水力阶段先把水车、传动轴和机械设备接成有效动力网络，再生产铁板、齿轮、轴承并运送物料；之后推进蒸汽和电气化。

## 生存与补给

### 身体状态

除生命、饥饿和体力外，生存系统还记录口渴、营养、感染、湿润与体温等状态。不同食物的效果并不相同：有些食物补充水分，有些加工食品反而增加饮水需求，生食也可能增加感染。

木材、金属等工业物品与具体食材、种子、原水、净水分别管理。不要把工业库存中的“食物”一项直接当作所有烹饪原料。

感染达到50后会自行恶化，较低感染才会缓慢消退；饱食不能代替补水与处理感染。真实房间能降低天气暴露，单铺地板或靠近地点图标不会自动获得庇护。

### 饮水

在生存手册选择附近可见水域，可反复收集原水，每次1份，不扣水域库存，也没有额外容器前置。原水饮用恢复30水分并增加25感染；净水恢复40水分。研究烹饪净水后，靠近合法石炉，用原水1、普通燃料1煮成净水1。降雨会缓慢改善角色水分，但不会直接把瓶装净水放入背包。

### 农业与野生动物

可种植胡萝卜、土豆、玉米、小麦、番茄、南瓜、豆和药草。作物有各自的温度范围、耗水和生长周期；土地湿度、天气和环境会影响生长，不能只按配方表里的基准秒数判断必然成熟。灌溉泵需有效机械动力和水源，工作范围及目标以生存界面提示为准。

翻土每格消耗木材1，要求未被占用的草地或泥地；播种消耗对应种子1，收获返还种子2或3。原水和净水均可浇田，每份增加40湿度。过旱、过冷或过热会损害作物，成熟后也仍需照料；过湿会降低生长速度。农业是当前可持续补给的重要来源。

当前有野兔、鹿、野猪、野鸡、狼、熊、狐、山羊、野牛、羊、野鸭、雉12种动物。胆小动物会逃跑，防御型动物可能反击，捕食者有自己的活动逻辑；“动物”并不都代表安全的食物来源。

动物仅在初始区域按合法条件尝试投放，最多32只；当前没有繁殖或死亡后补刷路径。猎杀后需靠近并无遮挡地分解尸体，食品库存必须能完整接收肉类；不要求先做军刀。树木和补给箱的附带野食只在手动采尽时结算一次，矿机采集或攻击摧毁不提供这份奖励。

## 探索与资源

新世界使用可向正负坐标扩展的稀疏区块，每区块16×16格。初始64×64区域不是整个世界边界。世界会逐步生成在线存活角色周围的区块，并受全局坐标、区块和实体容量限制；“持续扩展”不代表数学上的无限。已经耗尽的资源不会因离开、重新加载区块或读档而补满。

### 群系与材料

当前群系包括草甸、阔叶林、针叶林、荒漠、湿地、冻原，以及后续接入的沼泽、雪山、樱花林、河谷。群系是资源分布的方向提示，不保证每个小区域都有所需矿物。

| 需求 | 寻找方向 |
| --- | --- |
| 木材与早期燃料 | 优先探索森林，观察自然树木 |
| 石材与黏土 | 查看实际资源节点及当地提示；黏土与岸线环境有联系 |
| 铜、锡与铁 | 多探索不同群系和矿脉；铜锡用于青铜，铁材用于后续工业 |
| 煤、石灰石、耐火黏土 | 为焦化、炼铁、炼钢和耐火设施提前勘探 |
| 原油 | 使用石油勘探提示定位有限油藏，再用抽油机采集 |
| 石英 | 高压精密工业的起点，开采后用于工业硅 |
| 铀矿 | 核工业原料；实际开采后还需研究选冶、化工处理与燃料加工 |
| 废料与补给 | 自然废料节点、建筑容器和相应加工来源 |

更具体的寻找倾向：煤偏针叶林、冻原；石灰石偏雪山、河谷、荒漠；耐火黏土偏沼泽、湿地、河谷；石英偏雪山、荒漠、河谷；油藏偏沼泽、荒漠、河谷、湿地。其他群系仍可能有背景资源，以上均非必出保证。当前生成器还会在出生附近缺少可达石英时尝试补充露头，但没有等价的初始油藏保障。石油勘探只搜索48格内已生成且未耗尽的油源，不生成远处区块或直接发放原油。

工具奖励按实际节点余量和背包容量结算。满包时先整理库存；矿点库存少时，不会因为高级工具而额外凭空产出。原油不提供徒手采集路线。

### 聚落、建筑与楼层

聚落和自然群系是不同的生成层：工业区、市区、郊区、乡村等环境影响建筑用途与分布。医院、超市、公寓等并非在所有地区都会生成。自然建筑有真实入口和内部空间，部分建筑有楼层或地下层；按门和楼梯等实际交互点进入。

屋顶和外壳会随本地角色所在空间切换显示。看见屋顶或高层立面并不表示可以直接穿过墙体；开门、通路与楼层可达性仍由真实建筑决定。

### 四季、天气与地图

春夏秋冬各7个游戏日，28日为一年。默认一天240秒，对应一季28分钟、一年112分钟模拟时间；世界关闭期间的现实时间不会推进季节。天气在世界范围内共用，包括晴、阴、毛雨、雨、雷暴、雾、热浪、寒潮、雪、沙尘，群系温差另外叠加。

迷雾由各角色分别记录，队友不自动共享探索记录。当前可见半径白昼12格、夜晚8格，雾和沙尘降为6格，雪和雷暴最多9格。揭图按距离计算，墙体不阻挡揭图；战斗与交互仍另有遮挡检查。已经探索不等于当前可见，油藏勘探也不等于揭开地图。

## 建造与基地

建造需要当前科技、对应材料、可放置地面和完整占地空间；还要考虑朝向、视线、工作距离、墙体和其他设施。对多格设备，不能只清空锚点那一格。

| 基地组成 | 作用 | 注意事项 |
| --- | --- | --- |
| 防护墙、出入门 | 围护、阻挡敌人和通行管理 | 关门阻挡通行，开门后才可穿过；围合决定室内空间 |

| 机枪塔与防线 | 自动攻击丧尸 | 需要对应电力与9mm弹，不等于自动补弹 |
| 农田与供水 | 持续生产食物 | 水分、温度和供能等条件影响实际收益 |

建筑维修与装备维修是不同操作。扳手能改善部分维护或回收效果；拆除前整理背包空间，否则设备库存、返还建材和运输物品可能无法全部接收。

房间要求真实墙门围成不通外界、无水的区域；开门仍保留房间边界，拆门或拆墙形成缺口会失去庇护。门口有人或活体生物时不能关门。楼层来自自然建筑蓝图，按楼梯前往相邻层；目标落点被占用时拒绝迁移。当前没有玩家自由建造任意楼层的完整系统。

### 推进顺序

**原始 → 水力。** 研究并生产青铜、铁、陶砖和木炭，完成对应建造前置。烹饪净水是可选生存支线，不能把所有可选研究都当作时代晋升条件。

**水力 → 蒸汽。** 用真实水车和传动轴驱动粉碎、冶炼、压板、部件生产及装卸送达。灌溉磨粉是可选支线。机器相邻不会自动替代传动轴连接。

**蒸汽 → LV。** 焦化和耐火材料可并行发展，再汇合为生铁、钢、机床、管件、锅炉与蒸汽驱动。首批机床可用水力轴系启动，不需要先有蒸汽机才能加工第一套蒸汽设备。

**LV → MV。** 先利用既有机械设备制作铜线、绝缘件和线圈，手工装配首批电机与继电器，再建立电加工、电路与装配产线。推进还要求物流、过滤和受保护电网的真实工作记录。

**MV → HV。** 勘探与开采原油，输送并分馏，处理轻重馏分，生产柴油、聚合物、润滑油和冷却液。初期石化设备使用LV电力，先用已有电网启动，再发展中压扩产。

**HV → 核工业。** 从石英制备工业硅，提纯、切晶圆、封装器件，再制造高级电路、精密部件和控制模块；耐热合金可与电子链并行推进。首批精密材料设备使用MV电力。

**核工业内部。** 实际采集铀矿后研究铀矿选冶，在MV化工厂生产铀精矿，再送入HV核燃料处理机；反应堆必须配齐控制、外部供电、冷却和废料专用仓。核时代研究并非全部默认完成。

## 能源与物流

### 动力与电压

| 类型 | 供给与连接 | 典型用途 |
| --- | --- | --- |
| 机械动力 | 水车或蒸汽引擎，经直接相接的传动轴分配 | 粉碎、鼓风、压板、部件、机床、机械绕线 |
| 蒸汽动力 | 完整锅炉模块，经蒸汽管连接 | 蒸汽采矿机、蒸汽高炉、蒸汽引擎、蒸汽轮机 |
| LV低压电 | 燃料发电机、蒸汽轮机、低压电线杆 | 电加工、自动装配、初期石化与炮塔 |
| MV中压电 | 柴油发电机、太阳能板、中压电杆 | 化工扩产、冷却、硅材精炼、电子工台 |
| HV高压电 | 高压发电机、核反应堆、高压电杆 | 精密装配、核燃料处理、反应堆控制 |

不同电压不能直接靠相邻电杆混接。变压器默认MV降LV，可切换为HV降MV；输入上限200kW、效率90%。电杆的连线距离为7格、供电范围4格。设备供能不足时可能减速或停机，先看实际网络状态，不只看附近是否有发电机。

缺原料或满仓的设备仍计入额定电网需求，处理停机设备也有助于降低总负载。机械与蒸汽转换分别经过对应设备，蒸汽引擎和蒸汽轮机不能互相替代。

太阳能板在HV时代自主制造，但输出MV电力；抽油机与首批石化设备在MV时代解锁，却使用LV电力。机械绕线台也仍消耗机械动力。

### 模块锅炉与核设施

模块锅炉需要燃烧室、锅炉、取水泵和烟囱沿边组成有效集群，另需燃料、取水与蒸汽连接。取水泵可以隔一格完整外墙取水；不能把任意远处水面当作有效进水。

核反应堆需要同一高压网络中启用的控制台，控制台还要有外部电源，不能依靠尚未启动的反应堆自举。反应堆正面输出核废料，面朝输出箭头时右侧输出热冷却液；布置时先安排专用仓和冷却回路。

核废料不能作为普通背包或物流物品随意收发。专用仓只接收合法反应堆输出；研究专用废料转运后，才允许相邻专用仓间自动转运。基础专用仓容量200，屏蔽仓体研究后提高到400。

基础反应堆最高输出1200kW，一份燃料维持20秒、一份冷却液维持2秒，900℃自动停堆，降至300℃解除温度锁。相应研究可分别提高至1500kW、30秒、4秒、1100℃；这些是独立升级，不是进入核时代后直接全部拥有。

### 辐射与核作业防护

辐射暴露与防护服已接入，不依赖生存模式开关。反应堆有剩余燃料或正在发电、设施存有核废料，以及废料转运时，都可能产生附近暴露。环境率按距离衰减，墙体不参与当前辐射查询。只停下出电但仍有燃料，不代表暴露立即归零。

先实际开采铀矿4份并研究铀矿选冶，再研究辐射监测和核作业防护；这些可在首次装料前准备。监测研究开放环境暴露率、个人累计暴露和防护读数，未研究监测时也仍会受到实际暴露。读数使用游戏单位，不代表现实辐射剂量。

核作业防护服制作成本为聚合物6、钢板2、耐火砖2，另需核时代、核作业防护研究和合法工作台。防护服占躯干槽，最大耐久150，有效穿戴时减少80%辐射暴露；仅放在背包里无效。处于暴露区时约每2秒磨损1耐久，耐久归零失去防护。

累计暴露上限100，达到30开始持续损害生命；离开所有辐射影响后，每秒恢复2点。防护服降低新增暴露，并不会立刻清除已有累计值。复活清零当前累计暴露与辐射磨损计时，但不会恢复防护服耐久。

### 物料流动

- 传送带按箭头运送物品，每段容量2，无需供电。储物箱和设备输出方向同样影响线路。
- 机械装卸器需要有效机械动力；过滤分流器需要LV电力，所选物品送前方，其余送左侧。
- 液体管道按方向和选定液体工作。切换液体种类前，需要管段或容器排空，并且没有相应在途液体。
- 副产物也是实际产物。原油分馏的重质馏分或化工原料满仓，会阻塞整批生产；晶圆、精密装配等也要安排热冷却液去向。
- 普通箱、传送带、装卸器和分流器运固体；液管与储液罐运选定液体。普通机器只有一个正面出口，分馏的多种液体需要轮换液种或人工取出其他产物，当前没有通用的多出口自动分离。
- 低压断路器过载跳闸后，先降低负载，再人工复位。反复点击而不解决过载不会增加供电。

## 战斗与复活

近战与射击由人物朝向、距离、遮挡、冷却、耐久和当前装备状态共同决定。枪械还要有兼容弹药并完成装填；弹匣中的数量与背包弹药不是同一份库存。

枪械按即时射线结算。装填结束时才扣背包储备，切换装备或死亡会取消装填；弹匣非空时不能直接更换弹种。自动战斗没有合法目标时不会空挥或扣弹药；手动攻击仍可能消耗耐久和弹药。当前攻击本身不直接消耗体力。Alt瞄准缩小散布但减慢移动，并禁止冲刺。

普通弹通常最多命中1个目标，狙击步枪普通弹最多2个，穿甲弹最多3个，连续目标伤害依次衰减；穿透仍受地形和阻挡物截断。不能只凭准星颜色判断射线一定无遮挡。

丧尸和野生动物都能参与玩家战斗，但机枪塔沿用针对丧尸的自动防御规则。墙、门和其他有效障碍会影响攻击与通行，不能把视觉上靠近目标当作可以穿墙命中。

### 丧尸与尸潮

当前敌种有普通、快跑、暴徒、爬行、喷吐、装甲、燃烧、尖啸、防化、冻伤、自爆、夜行精英12类，按波次及环境条件进入生成选择。远程喷吐、火焰、寒冷、毒雾、尖啸与自爆等行为需要分别应对，围墙和资源也可能被敌人破坏。

初始区域尝试投放少量敌人；首波默认在180秒开始。后续尸潮数量和间隔随波次及存活人数变化，另有满足条件时的补刷，因此清空初始敌人不等于世界永久安全。

### 死亡与复活

当前死亡不掉落背包或装备，也不清除成长。死亡后等待至少5秒，并找到安全落脚处才能复活；成功后生命、体力恢复，饥饿至少45，并获得5秒敌对伤害保护。生存状态还会恢复最低水分与营养、清除部分负面状态，但不补发食物、水和种子；世界科技继续保留。

## 合作与存档

### 单人和局域网

新建或读取世界会启动房主，没人加入时也可以独自游玩。多人世界由房主运行模拟，客户端发送操作意图；工业研究和工厂进度属于世界，角色个人状态分别保存。当前最多4人同时在线，一个世界最多保存8个持久角色槽。部分界面人数分母显示8，不能据此当作8人同时联机。

房主先“新建世界→创建世界”，或选择本地存档后读取；队员在“局域网联机”填写角色名和房主完整IPv4地址，再加入世界。当前使用UDP 7777，约15秒连接超时会提示检查同一局域网和网络条件。当前没有房间码、自动匹配或已接入的房主迁移。房主离开后，客户端返回菜单。

建议各方使用相同游戏构建；当前握手核对保存/协议格式号，标题上的应用版本号单独显示。同名世界和相同种子不会自动加入同一个世界。角色由本机持久身份识别，修改昵称不等于创建新身份，也不能保证重命名已存在的旧角色。

### 保存与读取

保存由房主执行。当前创建世界后会尝试保存，运行中约每30秒自动保存，也可按F5或点击菜单保存；离开世界及正常退出也会尝试保存。队员不能代房主保存。退出前可先手动保存并确认反馈，不能把“已返回主菜单”当作保存一定成功的证据。

在读取世界列表中先选择存档，再确认加载。删除存档也需要先选中条目，并通过显示世界名等信息的确认框。多人游戏的菜单不会代替房主暂停世界。

世界保存在应用持久数据目录的`Worlds`文件夹，文件按世界ID区分；覆盖保存会保留上一份`.bak`。删除操作同时移除主档、临时文件和备份，没有内置恢复入口。列表会跳过读取失败的档案，因此列表未显示不必然表示文件已被删除。

## 常见问题

**进入时代后为什么还造不了机器？** 时代与工艺研究分开。查看对应节点的研究、实际产量、材料与工作台要求。

**背包里有青铜或铁，为什么生产进度没完成？** 拾取、搬运和回收不等于真实生产；某些阶段还要求合法动力网络内加工或运输实际送达。

**石制工具为什么需要石材？** 当前石斧、石镐的制作和维修都使用石材；研究样品也使用石材。界面中的制作材料和研究材料分别显示，不能用铁矿替代石材。

**开局的教程工作台在哪？** 当前自然开局不放置固定教程设施，需要自己用木材6建造工作台；旧资料里的固定坐标与设施说明不适用于当前生成器。

**已经开门，为什么附近的工作台仍不可用？** 当前工作台视线检查也把门占地计作障碍。尝试站到与工作台同侧，再检查2.4格内距离和其他遮挡；这不代表门仍无法通行。

**水车旁的机器为什么不工作？** 检查岸边放置、传动轴是否沿边连通、设备是否接入同一动力网络，以及原料、配方和输出空间。

**为什么越发电仍越缺电？** 先核对电压等级、连线距离、供电范围、变压器损耗、负载和断路器状态。蒸汽和机械动力不能直接替代电力。

**分馏或化工为什么突然停产？** 检查所有副产物缓冲、选定液体、输出方向、水源、燃料与冷却条件，不要只补主原料。

**为什么离开矿区再回来，矿没有刷新？** 自然资源有有限库存，耗尽记录会保存。继续探索新的矿源。

**为什么不能喝工艺水？** 生活饮水与工业液体分别管理。饮用与烹饪使用生存系统中的原水或净水。

**为什么有枪、有弹仍不能射击？** 检查武器是否装备、弹种是否兼容、弹匣是否装好、是否正在装填、耐久和操作冷却；打开界面时世界输入也可能被拦截。

**为什么核反应堆无法自行给控制台供电启动？** 控制台需要外部电源联锁；先启动外部高压供电，确认冷却与专用仓后再运行反应堆。

**武器工具研究树在哪？** 打开科技树后选择“武器”或“工具”筛选。节点详情会显示前置、样品、真实产量和缺少的条件；背包制作条目也提供“查看研究”入口。合法持有的装备不因制造研究未完成而失效。

**为什么第5名玩家进不来？** 同时在线上限是4人，持久角色槽8个用于保存先后加入的角色。

## Wiki维护

### 更新时机

修改玩家可见的玩法、配方、数值、研究条件、操作、界面入口、联机或存档行为时，在同一提交中更新本页相应章节，并同步相关专题资料。仅修改内部实现且玩家行为未变时，核对受影响章节即可，不必编造玩法更新。

维护顺序：

1. 先核对实现与现有测试，再改玩家说明；文档与代码冲突时记录实际行为，修复另行明确。
2. 先更新正文中的旧规则，再修改最后核对日期、规则基线和更新记录。只改日期不算完成维护。
3. 新功能只在真正接入后从规划表转入当前玩法；数值原型、设计候选和历史记录保持各自边界。
4. 检查目录锚点、相对链接、目录名称和已有操作入口；配方或目录改变时核对表格覆盖。
5. 验证记录只写本次实际执行的检查，分别说明静态核对、核心检查、Unity运行与联机覆盖。
6. 修改本Markdown后，在项目根目录运行 `python Tools/generate_wiki.py` 生成 `Docs/WIKI.html`，再运行 `python Tools/generate_wiki.py --check` 检查同步；源稿与HTML在同一提交中交付。HTML内嵌样式、脚本和游戏图片，可单文件离线阅读。页面模板、样式与交互源位于 `Tools/Wiki/`。
