## 本轮实施范围与顺序

本轮把通用框架与三台首批设备作为一个可玩的交付闭环。玩家必须装备并手持耐久大于零的扳手，先选择大型建筑，再从专属模块菜单选部件，逐格自由画蓝图。先放一个控制器建立蓝图组，之后每次只放选中的单个模块，R旋转该模块；没有预铺的整机形状。画图不预扣建材，退出绘制后再靠近各格分批投入该模块需要的材料。控制器、机壳、工艺单元、物品输入／输出总线、能源接口、维护口和排气口各有职责，不能用普通墙体或随意相邻设备替代。

| 顺序 | 本轮目标 | 依赖与验收 |
| --- | --- | --- |
| A 通用结构 | 自由模块列表、独立朝向、单格占用、模块菜单、自由绘图与分批投料 | 无扳手拒绝；不能重叠、超收；覆盖负坐标与跨区块；当前格式保存恢复 |
| B 接口网络 | 输入／输出端口与能源接口 | 机壳不接货、不接动力；未成形不生产、不接收自动物流；断线与堵塞安全停机 |
| C 首批设备 | 大型蒸汽高炉、基础装配厂、矿物处理厂 | 使用既有材料与研究，不形成首机自锁；真实供能、批次结算与产出证据 |
| D 维护合作 | 检修、修复、取消／拆除、多人共享施工进度 | 仅从操作者背包扣料；重复指令不超收；退款容量检查；读档、在途与维护守恒 |
| E 后续扩展 | 锻压厂、蒸汽动力总厂、化工塔、精密控制工厂 | 仍为后续；先通过首批闭环，再增加流体多接口、并行升级与热压安全模型 |

本轮采用自由形状：模块坐标与朝向由玩家逐格决定，包围盒内没有模块的空隙不预约、不阻挡。形成检查核对必需职责、模块数量、四邻接连通与端口外侧，机壳允许额外增加；不要求3×3或固定九格。每台最多32个模块、跨度最多12×12，用于限制施工与模拟预算。额外机壳不自动增加吞吐；多能源／多输入输出、工艺并行升级、多层塔体及热压事故仍为后续。核心公开行为以 WorldSimulator.Apply、Step 和当前格式恢复为检查边界；界面与联机实测结果另行记录。

大型工业机械由控制器、结构方块、功能模块和接口组成，是可进入工业建筑中的多方块设备。玩家先搭建主体，再配置能源、物流、维护和工艺模块；结构完整、网络连通且条件满足后才能运行。

参考格雷科技的多方块机器、材料等级、输入输出接口和维护要求，但不直接复制其配方、机器名称、数值、科技阶段或电压规则。设计服务于 DeadCircuitDemo 的俯视角 2D 生存、合作建造和权威模拟。

目标是让大型机械成为基地布局、资源运输和团队分工的核心，而不只是速度更高的单格机器。

## 2. 设计原则

- **结构先于数值**：产能来自完整结构、有效接口和稳定供能，不只来自升级按钮。
- **模块可替换**：主体可以更换能源、输入、输出、过滤、维护和控制模块。
- **状态可读**：明确显示缺件、未成形、待供能、待维护、阻塞和运行状态，并指出主要原因。
- **旧设备仍有价值**：大型机械提高吞吐和自动化能力，不让水力、蒸汽和小型设备失去用途。
- **合作有分工**：采集、建造、接线、运输、补料和维修都能成为有效分工。
- **规则可验证**：结构、产出、能源、流体、维护和副产物由 `WorldSimulator` 权威计算。
- **避免科技死锁**：首台大型设备不能依赖自身产物；材料必须有可走通的前置路线。

## 3. 格雷科技借鉴边界

### 借鉴

1. 多方块结构由控制器和外围结构共同组成。
2. 输入总线、输出总线、能源仓、流体仓和维护口承担不同职责。
3. 外壳材料影响机器等级、速度、容量和负荷上限。
4. 并行模块和高等级结构提高吞吐量。
5. 维护、堵塞、缺能源和接口方向属于生产线玩法。
6. 大型机器承担清晰的工业跃迁，例如从分散设备升级到连续生产。

### 不直接照搬

- 不复制 GregTech 的材料清单、配方比例、机器等级名称或耗时。
- 不为复杂而堆叠缺乏玩法差异的中间材料。
- 不隐藏结构规则；预览和检查栏显示缺失格位。
- 不把外部作品的电压数值当作现实标准；LV、MV、HV 仍是本项目的游戏分级。
- 不让维护退化成高频重复点击；维护由运行负荷和模块状态驱动。

## 4. 结构模型

### 4.1 基本组成

| 组成 | 作用 | 是否必需 |
| --- | --- | --- |
| 控制器 | 定义设备类型、朝向和主状态 | 是 |
| 结构外壳 | 形成边界，提供耐久和结构等级 | 是 |
| 功能模块 | 提供炉腔、压制、反应、装配或分离能力 | 按设备配方 |
| 能源接口 | 接收机械、蒸汽或电力 | 至少一个 |
| 物品输入口 | 接收矿石、部件、燃料或容器 | 按配方 |
| 物品输出口 | 输出成品、废料和副产物 | 按配方 |
| 流体接口 | 输入或排出水、蒸汽、油及化学流体 | 按配方 |
| 维护口 | 安装维护件、读取故障和执行维护 | 中大型设备必需 |
| 排气/泄压口 | 处理烟气、热量或压力副产物 | 热工、化工设备必需 |
| 控制扩展口 | 接入传感器、继电器和自动化条件 | 可选 |

### 4.2 结构合法性

- 控制器的位置由玩家决定，用于建立并标识同一蓝图组；各接口有独立朝向。
- 外壳、功能模块和接口由玩家自由选格，形成时必须构成四邻接连通体且满足职责数量；普通墙、门、其他机器不能自动补足结构。结构包围盒内的未放模块空隙保持真实可通行空间。
- 结构可跨区块，但由权威模拟统一重建；预览提示区块边界和未加载区域。
- 方块、接口、旋转或拆除才触发结构重检；库存、供能和配方按固定 tick 更新。
- 形成状态、容量和故障标记是派生数据，读取后重新计算。
- 机器可位于厂房内部，但仍是独立占地实体，不能由房间墙体或其他机器替代。

### 4.3 结构模板

| 模板 | 适合设备 | 特点 |
| --- | --- | --- |
| 箱体型 | 高炉、装配厂、压制厂 | 规则矩形，便于学习和扩建 |
| 塔式 | 蒸馏塔、烟气处理塔、储液塔 | 高度换取容量和分层接口 |
| 线性型 | 连续轧机、传送处理线 | 输入到输出方向清晰 |
| 环形型 | 反应器、冷却机、循环设施 | 强调流体回路和安全接口 |
| 厂房型 | 综合冶炼厂、化工厂、装配中心 | 多个工艺区共享外壳且相互隔离 |

这些形态是布局建议，不是首版强制模板。首版允许玩家自由画箱体、线性、L形或其他连通布局；真实多层塔体与环形流体回路需对应系统扩展，不能只凭外形认定已经实现。

## 5. 模块分类

### 5.1 结构模块

- 普通砖、耐火砖、青铜外壳、钢外壳、强化钢外壳。
- 结构等级决定热负荷、压力上限、基础耐久和可安装的控制器等级。
- 外壳只提供结构能力，不自动供能、输入或输出。
- 低等级结构可运行基础配方，但不能伪装成高等级设备。

### 5.2 工艺模块

- **炉腔**：加热、熔炼和精炼。
- **压制单元**：板材、杆件、管件和机械部件加工。
- **反应单元**：化学混合、分馏和聚合。
- **装配单元**：组合电机、控制器、传感器和工业部件。
- **分离单元**：处理矿物、液体和副产物。
- **冷却单元**：消耗冷却介质，降低热负荷并维持连续运行。

工艺模块数量不直接等同产量。控制器等级、能源、物流、热和压力共同约束实际吞吐。

### 5.3 接口模块

- **物品输入总线**：有限槽位和吞吐，按过滤规则接收物料。
- **物品输出总线**：分流成品、副产物和废料；满仓时按配方规则停机。
- **能源仓**：接入机械、蒸汽或 LV/MV/HV 电力，显示额定输入与供能比例。
- **流体输入仓**：区分生活用水和工艺用水，接收蒸汽、原油、冷却液等。
- **流体输出仓**：保存废水、烟气、重质馏分、废热等副产物。
- **维护口**：记录维护件耐久、故障原因和检修状态。
- **排气/泄压口**：没有合法排放路径时限制运行，副产物不凭空消失。

接口方向由控制器朝向和接口格位决定。传送带、蒸汽管、轴系和电缆只连接相容接口；相邻放置本身不代表连接。

## 6. 运行状态

设备使用统一状态，界面显示当前状态和主要阻塞原因：

1. **未形成**：结构缺件、位置错误或找不到完整模板。
2. **待安装**：结构完整，但缺少功能模块或接口。
3. **待供能**：输入完整，能源不足或类型不兼容。
4. **待输入**：能源正常，等待物品或流体。
5. **运行中**：输入、能源、输出容量和安全条件满足。
6. **输出阻塞**：成品或副产物无法排出，设备安全停机。
7. **待维护**：维护件耗尽或故障达到阈值。
8. **过热/超压**：超过结构等级后降载或紧急停机。
9. **损坏**：攻击、事故或灾害破坏结构，需要修复。

停机时不消耗未完成配方的输入、燃料、流体或维护件。已完成 tick 按比例结算，避免断电复制产物。

| --- | --- | --- | --- |

## 9. 建造与操作流程

1. 装备并手持扳手，从建造目录选择大型建筑，打开它的模块菜单。
2. 选择控制器并逐格放下首个蓝图格，再选机壳、工艺及接口等模块自由画图；鼠标只预览当前选中模块，不自动生成整机。
3. R旋转当前模块；可持续画机壳、擦除单格或选中已有蓝图继续绘制。只有实际画下的格被预约，菜单实时列出缺少的职责、断连与接口朝内问题。
4. 退出绘制后，对准具体格位左键或E分批投入建材；所有必需模块连通、方向合法且已建成后才形成机器。
5. 检查结构，得到缺件清单和下一步状态。
6. 连接轴系、蒸汽管、电缆、传送带和流体管路。
7. 放入配方、燃料、工艺流体和维护件，由权威 tick 驱动生产。
8. 处理补料、输出、排放、维修和防守；拆除控制器或关键结构时安全停机。

预览支持旋转、缺件清单、材料替换提示、碰撞检查、接口过滤和占地显示，不依赖玩家记忆隐藏规则。

## 10. 维护、风险与防守

- 维护件按运行时间、负荷和工艺危险度消耗；空转和停机不消耗。
- 缺件时先降速，再进入待维护；危险工艺到期后安全停机。
- 外部攻击优先影响暴露接口、排气口、能源线路和维护口，外壳提供缓冲。
- 首版用停机和结构损伤表达风险；爆炸、泄压、污染和火灾留待对应系统专项设计。
- 工厂可设置隔离墙、检修通道、紧急断路和手动泄压。
- 故障通过控制器面板、世界标记和声音提示表达，不只依赖颜色。

## 11. 物流与能源规则

物流总线拥有实际容量和吞吐，传送带、装卸器与管路不会把远端仓库变成无限速接口。跨区块运输保存物品、目标接口和在途进度；断线或读档不复制物资。客户端只发送建造、装卸和连接意图。

机器显示额定输入、实际输入、供能比例和转换损失。水力、蒸汽、机械和电力网络保持区分，只有明确的转换设备才能跨网络供能。供能不足按规则减速或停机；热量、压力、流体、燃料、成品和副产物按固定 tick 结算并接受守恒检查。

## 12. UI 与可读性

检查栏显示设备名称、模板、控制器位置、朝向、形成状态、阻塞原因、外壳等级、模块数、当前配方、剩余时间、吞吐、能耗、热/压、接口库存、维护状态及连接网络。连接中断时定位断开的接口或区段。

建造模式提供结构、能源、物流、维护四种视图。世界视图只显示附近和选中设备的接口标记，避免基地内标记过载。

## 13. 数据与实现边界

本轮机器定义集中于ModularMachineCatalog，设备实例由BuildingState持有自由modularModules列表；每格保存职责、世界坐标、独立朝向和paid建材账。实例另保存整机库存、配方进度和维护批次，连接与形成结果由权威模拟重建。包围盒仅用于粗筛和显示，不代表实心占地。

- 结构检查、配方、网络和守恒放在 Unity 无关的 `Core/` 模拟层。
- `GameBridge` 接收建造、检查、连接、启动、维护和拆除指令。
- `DemoWorldView` 呈现结构、接口、运行效果和损坏外观，不自行判定产出。
- `DemoHud` 呈现蓝图、检查栏和缺件信息，不直接修改世界状态。
- 机器图块复用现有 32×32 像素风格，以图层组合结构和运行效果，不为每种结构制作整张大图。

## 14. MVP 实施顺序

### 阶段 A：通用结构框架

- 定义自由模块列表、控制器、各格独立旋转、稀疏占地与连通形成检查。
- 实现选建筑后的模块菜单、单格预览、逐格绘制／擦除、缺件清单和错误格定位。
- 验证跨区块、负坐标、拆除、重建和保存恢复。

### 阶段 B：接口与网络

- 接入物品输入/输出、能源仓、维护口和排气口。
- 复用现有水力、蒸汽、机械和电力网络连接规则。
- 实现输出阻塞、供能不足、在途物品和停机恢复。

### 阶段 C：首批设备

- 大型蒸汽高炉：热、焦炭、排烟和钢铁产线。
- 基础装配厂：物品总线、并行模块和 LV 自动化。
- 矿物处理厂：线性结构、多输出和副产物堵塞。

### 阶段 D：维护与合作

- 增加维护件、故障原因、检修通道和手动安全停机。
- 验证多人同时建造、补料、维修、拆除和重连。
- 加入工厂选址、危险区隔离和防守压力。

### 阶段 E：化工与精密工业

- MVP 通过后加入分馏与化工塔。
- 再加入精密控制工厂、冷却和高级电路。
- 核能设施另行设计，不在此锁定堆型和燃料规则。

## 15. 完成判据

- 新世界材料能建出首台设备，且不依赖自身产物。
- 结构检查、旋转、跨区块、拆除和重建结果确定。
- 缺输入、缺能源、输出堵塞、维护到期和结构损坏均可停机、恢复。
- 成品、副产物、能源、流体、燃料和维护件无复制或凭空消失。
- 保存恢复后结构、接口、网络和未完成工艺保持一致。
- 单人和多人均能完成主要流程，客户端无法伪造结构形成或生产。
- 核心检查覆盖结构合法性、网络连接、停机恢复、守恒、负坐标和跨区块。
- Unity 编译通过，并完成人工界面操作和运行验证；纯源码检查不替代 Play 测试。
