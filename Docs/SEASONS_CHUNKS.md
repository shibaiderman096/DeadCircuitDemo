# 四季、稀疏区块世界与探索迷雾

## 世界与加载

新建世界菜单默认使用稀疏区块世界。地图不再受 64×64 或 256×256 边界约束，可以沿正负 X/Y 四个方向持续探索。每块 16×16 格，使用全局整数坐标；负坐标按向下取整划分区块。

当前全局格坐标范围为每轴 [-1,048,576, 1,048,576) 格。这是近似无限的二维世界，不含高度层、洞穴维度或 Minecraft 方块的复制；尚未实现浮动原点，极远位置的单精度抖动不在本轮验证范围。

- 原 64×64 出生区、教程设施和动物保留原坐标；出生点仍为 (32,35)。初始区拆成 16 个已生成记录。新世界不再投放起始固定资源，起始箱为空。
- 主机按所有在线存活玩家附近半径 3 个区块预加载。每个 50ms tick 至多生成一个缺失区块，优先最近的块。移动跨过区块边界后自动补齐前方；不是每走一格就重复生成脚下的整块地图。
- 区块按种子和全局坐标采样连续地势、河流、温度、湿度与群系，再生成植被、矿团、道路、可进入的墙体建筑和有限补给。
- 原教程出生区保留既有布局，是全局采样的特例；出生区与外部程序地形的接缝尚未做美术平滑。
- 同种子与生成设置产生相同区块内容。实体 ID 是主机分配的存档身份，不作为地形随机源；访问顺序可以改变 ID，不能改变地形和资源布局。
- 已生成区块始终保留在权威状态和存档中，返回时不重造。开采、拆墙、开门、建造和库存变化不会被区块加载重置。
- 视图只维护本地角色附近区块，每帧最多建立或更新两个区块网格；移出范围释放网格。已探索数据仍在主机内存中保存，尚未实现单个区块的磁盘流式换页。
- 碰撞和敌人寻路使用全局 64 位格子键。未知区块不能行走、建造或穿越寻路。敌人寻路场限制在活玩家附近，避免扫描整个已探索世界。
- 工厂和物流由主机持续模拟，卸载画面不暂停机器，也不取消或复制在途货物。
- 房间只在局部墙体边界附近识别，不分配全局二维数组。单个相连墙体组件的检测包围盒含边缘最多 256×256 格，超限保守判为户外；这不是整张地图的边界。

2026-11-20 取消起始区固定资源：普通世界与区块世界均移除教学区固定树木、矿石、石材、黏土、蒸汽矿床、废料及补给箱，固定建筑箱内不再赠送木材。自然资源与已生成区块的耗尽/保存行为沿用现有规则。公开生成入口定向检查22/22、基于 `8f96765` 的隔离完整核心检查617/617通过（20项历史检查跳过）；本轮未运行Unity/Play或人工试玩。

## generator9：大片连续群系

新世界采用 generator9，参考 MC 大片群系的空间观感，继续由共享绝对坐标连续场与固定优先级阈值分类生成。16×16 只是存储和加载区块，不是方形群系版块；区块内不重新抽取群系，访问顺序不参与气候采样。

| 海拔主场 / 叠加场 | 40 / 80 | 240 / 480 |
| 湿度 | 40 | 240 |
| 温度 | 48 | 288 |
| 森林场 | 64 | 384 |

| 域扭曲每轴最大偏移 | ±9 | ±54 |

| 土壤 | 12 | 12 |

主群系相关采样尺度整体放大 6 倍，河流单独放大 4 倍。域扭曲使用 `(noise - .5) * 108`，每轴最大偏移为 ±54 格；扭曲坐标以浮点数参与噪声采样，避免先取整造成台阶。河流水面与河谷的判定带宽（场值阈值）同时除以 4，抵消整条河随采样尺度等比增粗；土壤保留 12 格细节。

大片温湿气候区构成背景，海拔与森林场形成内部地貌差异，独立河流场贯穿其间形成河道与河谷廊道。6 倍指采样尺度，不是实测群系直径或面积；不保证每片群系最小直径，也不保证出生 64×64 区域包含全部十类群系。本轮不新增美术，不做真正的板块地质模拟，也不引入真实汇流或软评分混合；完整群系定义与边界见 BIOMES.md。

## 季节

四季各 7 个游戏日，28 天一年。日长沿用世界设置；默认一天 240 秒，故一季约 28 分钟。季节只由主机已模拟时间推导，退出游戏期间不会按现实时间推进。

天气换相时应用季节权重：春秋偏温和、多雨雾，夏季增加雷暴和热浪，冬季增加雪与寒潮。夏季不新抽取雪/寒潮，冬季不新抽取热浪。已有存档中尚未结束的天气相位继续原插值，到下一相位才换用权重。

季节温差平滑变化并作用于体感温度、口渴、作物生长温度门槛、冻热伤害与土壤蒸发；不是仅更换 HUD 标签。世界材质色温平滑调整。未增加位图贴图，继续使用现有 SVG 来源资源。

## 小地图

小地图为跟随本地玩家的 64×64 格窗口，支持正负坐标。

- 未探索：黑色；当前圆形视野内：清晰；已探索但离开视野：变暗。
- 敌人、动物和队友的标记只在当前视野内绘制；建筑标记按已探索格裁切。
- 探索记录按角色、按区块保存，四个格子压为一个十六进制字符。其他玩家不会继承本地玩家的探索记录。
- 视野白昼 12 格、夜晚 8 格；雾/沙尘暴 6 格，雷暴或雪不超过 9 格。死亡或离线角色不继续揭图。
- 当前是圆形距离探索，未实现逐墙射线视野遮挡；已探索建筑使用当前状态，不是历史情报快照。

## 存档与局域网

本轮只面向 generator9 新世界，不考虑旧存档迁移、群系重解释或补生成。下段保留旧阶段的版本与协议说明作为历史，不作为本轮当前协议号或旧存档兼容承诺；本轮不改动这些历史编号。

区块存档自 v8 引入。当前存档及局域网协议为 v10（dc.cmd.v10 / dc.world.v10），支持迁移 v1–v9。原有限世界继续使用 64×64，已有稀疏世界继续使用各自的 generator3 或 generator4，保留已生成地形和资源。新稀疏世界使用 generator5，加入聚落分区和可进入的独立楼层，详见 SETTLEMENTS.md 与 FLOORS.md。局域网双方须使用同一协议版本。

区块、迷雾和嵌套状态在恢复时校验并深拷贝；拒绝重复区块、无效坐标、未知地形上的实体和错误位图。每个客户端仅接收自己周围半径 4 的区块及附近实体，最多 81 个区块；主机仍保存完整权威状态。客户端快照是表现投影，不能当作完整世界存档恢复。

保留独立世界文件与上一份 .bak，保存上限调整为 128 MiB。反序列化防护另有限制：最多 65,536 个已生成区块、1,000,000 个节点、16,384 个建筑、32,768 个生成地点；这些是当前 Demo 的存储/资源预算，不代表坐标边界。区块或实体预算不足时整块拒绝、不消耗 ID，显示一次说明；预算未改变时不反复生成失败块，已有区块仍保留。文件超出 128 MiB 则拒绝覆盖上一份良好存档。尚未实现按区块磁盘换页、区块增量网络包和浮动原点。
