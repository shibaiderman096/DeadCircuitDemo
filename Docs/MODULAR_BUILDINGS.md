# 可进入建筑区域与模块化蒸汽厂房

建筑由地图中的墙格、门格和内部区域组成。住宅、仓库、工厂等地点保留真实逐格外墙及地面；不渲染整栋楼的外观图片。机器独立占地，放在区域内仍然参与碰撞、生产和运输。

## 建造与进入

- 防护墙与出入门从原始时代可建。底部展开建造栏，1–0 选快捷格，T 科技目录可选全部设备；R 旋转。
- 靠近门按 E 或使用设备检查栏开关门。关闭时阻挡移动和射击，打开时允许通行。人物或活体生物占门口时拒绝关闭。
- 干地被完整的墙和门围合后识别为室内；机器、树和矿物不会被误当作房间边界。隔墙能够分出多个房间，内部隔门关联两侧房间。
- 门开启仍保留房间边界和屋顶覆盖。拆门或破坏外墙形成缺口后，区域立即变成室外，天气庇护随之消失；补墙或补门后恢复。
- 采用默认剖面显示：逐格绘制内部地面，墙遮住人物时淡化。屋顶不覆盖人物和操作区域。位置提示显示室内面积与出入口数量。
- 新生成世界为生成器第 2 版，每个探索地点入口有真实门。已有世界不重建、不补门，不改变已破坏墙体或物资。

## 蒸汽模块集群

蒸汽时代建造栏提供燃烧室、锅炉、取水泵、烟囱、蒸汽管、蒸汽引擎及蒸汽设备。各部件使用真实占地，旋转后尺寸同步变化。

| 部件 | 占地 | 作用 |
| --- | --- | --- |
| 燃烧室 | 2×2 | 每份燃料提供 20 秒燃烧时间、120 热功率；E 或物流补给燃料 |
| 模块锅炉 | 2×2 | 将集群供热、给水及排烟容量转为蒸汽，每台上限 120 |
| 取水泵 | 1×2 | 每台有效泵提供 120 给水容量；占地必须在干地 |
| 烟囱 | 1×1 | 每台提供 120 排烟容量 |
| 蒸汽引擎 | 3×2 | 消耗 60 蒸汽功率，输出 48 机械功率，经传动轴带动机械设备 |

燃烧室、模块锅炉、取水泵和烟囱须以占地边缘接触，组成一组或多组集群。对角、空气间隔、普通墙及蒸汽管均不传递集群内部热量和给水。蒸汽管负责将锅炉输出接到蒸汽设备或引擎，蒸汽轮机继续承担蒸汽到低压电力的转换。

取水泵可以紧邻水域，也可以通过一格完整外墙连接墙外紧邻水域。这是泵自带的短取水口，不能跨过空地、门、机器或多层墙取水，因此可以在完整的干燥厂房内运行集群。

总输出受锅炉、实际燃烧、有效给水和排烟中的最小容量限制。增加锅炉不会复制燃料或功率；多燃烧室按稳定 ID 选择所需数量，未使用的燃烧室不消耗燃料。缺部件或没有有效水源时停止运行且不继续烧料。燃烧结束的不足一 tick 余量按比例输出。

设备检查栏显示集群编号、部件数量、输出、各项容量及缺件/离水/无燃料状态。集群拓扑只在结构改变时重建；库存和水源状态逐 tick 更新。
