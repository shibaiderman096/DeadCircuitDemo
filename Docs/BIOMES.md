# 群系与自然地貌大纲

日期：2026-11-20

## 目标与范围

本文件规定新世界的自然地貌、连续群系生成、群系过渡、资源倾向和探索体验，作为后续生成器、资源分布、探索内容与美术制作的共同约束。

本轮在既有十类自然群系、连续气候场和跨区块采样基础上，使用 generator9 放大主群系的采样尺度，形成参考 MC 大片群系观感的连续区域。沼泽、雪山、樱花林、河谷沿用已接入的独立群系图集；本轮不新增美术，跨群系过渡图块仍属后续计划，也不做真正的板块地质模拟。

本大纲只面向新世界生成，不考虑旧存档迁移、旧存档群系重解释或旧存档资源重生成。后续实现可以直接按新的群系集合设计数据校验和新世界生成流程。

## 群系总览

### 当前已有群系

| 群系 | 气候与地貌定位 | 资源与探索体验 |
| --- | --- | --- |
| 草甸 | 温和、较开阔、起伏较小；作为多数自然群系的过渡基底 | 木材、野食、基础资源点和可建设空地较常见；视野开阔，适合早期探索、农田和聚落 |
| 阔叶林 | 温暖至温和、湿度中高；树冠连续但不形成不可穿越的密林 | 木材、果实、菌类和常见动物较丰富；遮挡增多，适合寻找废弃建筑、采集和伏击式遭遇 |
| 针叶林 | 偏冷、湿度中高、地形起伏更明显；林线和石地逐渐增多 | 木材、菌类、动物和裸露石地较多；视野受树木影响，路线较窄，寒冷天气下生存压力上升 |
| 荒漠 | 温暖干燥、植被稀疏、裸地和风沙地貌占主导 | 水源稀缺但容易发现裸露资源点和道路；食物、补水与夜间温差形成远征压力，建筑和补给点更有价值 |
| 湿地 | 湿度高、低地较多，水陆交错但仍保留连续陆地 | 原水、黏土、菌类以及部分金属资源点倾向增加；绕行、涉水边缘和低速路线构成探索节奏 |
| 冻原 | 低温、低至中等植被覆盖、开阔冷地；向更高地形或雪线过渡 | 裸露石地、菌类和少量生存资源较易观察；寒潮和积雪降低体温与补给效率，适合远程搜索和风险管理 |

现有六类继续作为基础气候群系的参考。它们不是按每格独立随机抽取，而是由连续地势、温度、湿度和河流场共同决定；同一种子和设置应得到稳定、可复现的自然结构。

### 已接入的新群系

| 群系 | 触发条件与边界 | 资源与探索体验 |
| --- | --- | --- |
| 沼泽 | 低地、长期高湿、积水或缓流密集；是湿地内部更饱和、更难通行的核心带 | 原水、黏土、菌类、药草和少量金属资源点倾向增加；可见陆地被水洼、芦苇和软地切分，路线选择与补给管理更重要 |
| 雪山 | 高海拔或高起伏地形与低温同时达到阈值；不是把冻原整片换成白色地表 | 裸露石地、金属资源点和高处建筑遗迹更有探索价值；雪、寒潮、狭窄山口和回撤路线形成高风险远征，通行依靠山口和谷地，不引入新的高度层系统 |
| 樱花树林 | 温和至偏暖、季节性湿润、起伏较缓，并与阔叶林保持相邻过渡 | 木材、野食、菌类和药草保持森林级别；以较高可见度的林间空地、花瓣覆盖和景观地标形成低压探索区，可承载聚落、补给点和非战斗探索目标 |
| 河谷 | 稳定河道、汇水带和两侧可通行低坡地形共同形成的狭长地貌；属于水文与地貌主导的群系 | 原水、黏土、肥沃耕地候选区和沿河资源点集中；河道提供方向感，浅滩、桥位、渡口和狭窄谷口提供路线决策，适合聚落与长距离运输通道 |

沼泽与现有湿地的关系是“外圈湿地、内圈沼泽”：湿地可以有较多水域，但仍以可连续行走的湿润土地为主；沼泽要求更高的积水、饱和度和缓流覆盖。雪山是冻原向高海拔冷地的扩展，不简单替换所有冻原。樱花树林是阔叶林的特殊生态带，河谷是沿河流连续展开的水文地貌带。

河谷的河道水面仍由独立的水面/地表类型表示。群系标签描述河岸和谷地环境，不把整条河错误地写成可行走陆地；水面、浅滩、河岸和谷地分别参与碰撞、采水、资源和建筑判定。

## 连续气候、水文与地貌分类

### generator9 的尺度与层次

`ChunkTerrain.Biomes.cs` 继续使用共享绝对坐标连续场和固定优先级阈值分类。主群系由海拔、温湿度、森林场等共同决定；相关采样尺度整体为原来的 6 倍，河流单独为 4 倍，土壤细节保持原尺度：

| 采样或参数 | 原值（格） | generator9（格） | 说明 |
| --- | --- | --- | --- |
| 海拔主场 / 叠加场 | 40 / 80 | 240 / 480 | 放大区域地势尺度 |
| 湿度 | 40 | 240 | 放大干湿气候区 |
| 温度 | 48 | 288 | 放大冷暖气候区 |
| 森林场 | 64 | 384 | 放大林地与特殊森林分布尺度 |
| 域扭曲采样 | 96 | 576 | 放大气候轮廓弯曲尺度 |
| 域扭曲偏移系数 | 18 | 108 | 公式为 `(noise - .5) * 108` |
| 域扭曲每轴最大偏移 | ±9 | ±54 | 系数 108 不表示最大偏移 108 格 |
| 河流 | 48 | 192 | 单独放大 4 倍 |
| 土壤 | 12 | 12 | 保留局部地表细节 |

河流水面与河谷的判定带宽（场值阈值）同时除以 4，抵消河流采样尺度放大带来的整条河等比增粗；这不是每处河宽固定的承诺。域扭曲后的坐标以浮点数传入噪声采样，不先取整，避免整数取整台阶；世界格坐标仍为整数。

生成层次为“大片气候区 → 区内地貌 → 沿河廊道”：温湿度与森林场形成大片气候背景，海拔在其中划分低地、平原和冷地山地等形态，独立河流场再穿过气候区形成河道与河谷廊道；土壤保留小尺度变化。它们仍由连续场叠加与阈值分类实现，不是预先切好的方形群系版块。

16×16 只是存储、缓存和加载区块，不是群系边长。上述 6 倍是采样尺度变化，不是实测每片群系的直径或面积增幅；不保证每个群系的最小直径，也不保证出生 64×64 区域包含全部十类群系。

### 采样字段

每个全局整数格使用同一种子和绝对坐标采样低频连续场。区块只负责缓存结果，不负责重新随机。目标字段范围为 0 到 1：

- elevation：相对海拔，决定低地、平原、丘陵、山地和水面基础。
- temperature：不含当前天气的基础温度，决定温暖、温和、寒冷区域。
- moisture：长期湿度，决定干燥、湿润和饱和土地。
- flow：汇水和排水强度，用来形成主河道、支流、河岸和低洼积水。
- riverDistance：到稳定河道或支流中心线的距离，用于生成河谷的连续宽度。
- roughness：局部起伏和坡度，用于山口、谷地、裸岩和道路可达性。

当前 generator9 直接计算 elevation、moisture、temperature、river 与 woodland，并用浮点坐标域扭曲和多层平滑噪声生成；flow、riverDistance 与 roughness 尚未成为独立采样量，后续可用于细化汇流、坡度和地貌。river 当前由低频噪声脊线近似，没有真实的流量累积或排水模拟。群系仍按稳定优先级阈值分类，没有显式保存候选权重或多层混合值；放大采样尺度不等于已实现软混合或新的水文模型。

temperature、moisture、elevation 和 flow 使用共享的绝对世界坐标、多层平滑噪声或等价连续采样方式。分类不能依赖区块内随机数、访问顺序或邻接区块是否已经加载，也不能用每格独立随机制造斑点。

季节可以平滑改变体感温度、降雨、积雪、蒸发、作物和生存压力，但不应每季重新抽取基础群系。基础群系、河道骨架和主要谷地在同一种子下保持稳定，季节只改变其表现和可用性。

### 目标分类顺序

后续目标方案采用“连续评分 + 稳定主标签”的方式。内部可以保留各候选群系的权重，最终每格存一个主群系标签；边界装饰和地表变体再根据邻域和权重生成。以下是后续软评分方向；当前 generator9 仍使用连续场与固定优先级阈值分类，本轮不实现下列完整评分流程：

1. 先由 elevation、flow 和地表水阈值确定水面、河道、湖岸和可通行陆地。水面不被普通群系覆盖。
2. 计算河谷、沼泽、雪山这类水文/地貌主导群系的连续评分。它们只有在形态连续且达到覆盖条件时才获得较高权重，不能因为单个噪声采样点突然出现。
3. 对剩余陆地按 temperature × moisture 计算草甸、阔叶林、针叶林、荒漠、湿地、冻原和樱花树林的气候评分。
4. 选择最高稳定评分作为主标签；评分接近时沿用连续场的空间趋势，并使用固定优先级解决同分，避免随访问顺序变化。
5. 只把确定性哈希用于树木、花瓣、碎石、菌类和资源点的装饰抽样，不用于改变群系边界。

后续阈值调整参考空间连续性和内容分布，不作为本轮游戏运行验收项。条件方向如下：

| 目标群系 | 初始条件方向 |
| --- | --- |
| 荒漠 | 高温 + 低湿度；若靠近稳定河道则退让给河谷或河岸带 |
| 冻原 | 低温 + 中低湿度；低海拔平缓地仍可保留冻原而不是强制生成山地 |
| 针叶林 | 偏冷 + 中高湿度，或较高起伏但未达到雪山条件 |
| 阔叶林 | 温和 + 中高湿度；作为樱花树林的主要邻接群系 |
| 草甸 | 温和或过渡气候 + 中低至中等湿度；作为大多数自然边界的缓冲带 |
| 湿地 | 高湿度 + 低至中等海拔，但积水和缓流未达到沼泽核心条件 |
| 沼泽 | 高湿度 + 低海拔 + 高积水/缓流覆盖，形成连续低地核心 |
| 雪山 | 高海拔或高起伏 + 低温，并且山口、裸岩和雪线具有连续形态 |
| 樱花树林 | 温和温度 + 季节性湿润 + 低至中等起伏，并且与阔叶林相邻 |
| 河谷 | 高 flow 或低 riverDistance + 两侧可通行坡地，沿河道延展而不是圆形斑块 |

这些条件是后续软评分的方向，不是互相独立的硬开关。当前版本通过共享的绝对坐标气候场、域扭曲和稳定优先级完成第一版硬阈值分类；水面与河流使用独立地表类型，普通群系的类别边界仍是分类边界，后续应增加邻域权重混合与专用过渡图块。

## 平滑群系与地貌过渡规则

### 通用规则

- 所有判定使用绝对全局坐标，跨 16×16 区块时边界必须连续；区块加载顺序不能改变地貌、群系和资源位置。
- 群系边界使用低频场和 smoothstep 一类的平滑权重。第一版建议让普通群系的主要过渡带宽保持在 8～24 格，并根据地貌尺度调整；禁止一格宽度的随机条纹。
- 每个过渡带至少包含“旧地表、混合边缘、目标地表”三个阶段。混合边缘可以通过边缘地块、稀疏植被和装饰密度表现，不要求立即增加新的独立群系编号。
- 过渡带中的资源使用两侧群系权重加权，并设置上限，不能在边界叠加出双倍资源。敌人、动物和建筑候选同样使用混合权重。
- 水面优先级高于普通地表；河岸、浅滩和湿润土壤沿河流方向连续生成。河谷不能表现成一串互不相连的圆形绿洲。
- 过渡只影响新世界生成。已生成区块一旦保存，其地表、资源、建筑、开采和建造结果不因后来调参而静默重生成。

### 典型边界

- 草甸 ↔ 阔叶林：先提高灌木和零散树木，再进入连续林地；保证至少有可见的穿行空地。
- 阔叶林 ↔ 樱花树林：保留森林地形和树木密度的大体连续性，只渐进改变花树比例、地面颜色、花瓣和景观点，不生成棋盘格花林。
- 针叶林 ↔ 冻原 ↔ 雪山：树木先变矮变稀，裸岩和低矮植被增加，再进入雪线、山口和雪地；雪山边缘必须留出回撤路线。
- 湿地 ↔ 沼泽：先增加浅水、泥地和芦苇密度，再进入积水核心；湿地外圈仍应保留连续陆地，避免出生点或建筑被水洼完全封死。
- 草甸/森林 ↔ 河谷：沿河道形成连续河岸和谷地，靠近主河道增加水、黏土和可通行浅滩；远离河道后逐渐恢复相邻气候群系。
- 荒漠 ↔ 草甸/河谷：由裸地、稀疏草、灌木和湿润河岸逐步转变，河谷只在有真实汇水和河道的地方出现，不能用一条绿色贴图硬切荒漠。
- 出生区 ↔ 外部自然世界：出生区可以保留教程设施和固定道路，但外圈应使用连续场做过渡环，避免固定布局与自然采样在区块边缘出现突兀直线。

## 资源、聚落与探索体验

群系只提供资源倾向和内容生成权重，不直接凭群系保证唯一关键材料。石材、黏土、铜、锡、铁、水、食物和基础建造材料仍须有可解释的勘探路径或替代来源，不能因为玩家出生在某种群系而永久失去推进条件。

2026-11-20 起，新世界取消起始区固定树木、矿物、废料、补给箱及箱内12木材；保留工作台、石炉、空箱子和既有出生地表。自然资源的群系倾向、种子采样和后续区块生成规则沿用现有实现，材料需向外勘探，不保证初始区域包含全部资源。公开 `WorldGeneration.Generate` 回归覆盖普通/区块世界、种子、预设和密度组合；基于 `8f96765` 叠加本次改动的隔离完整核心检查617/617通过。本轮未进行Unity/Play画面验收。

- **资源分布**：用群系评分、地貌评分和确定性资源点哈希共同决定节点。河谷和沼泽提高水、黏土、湿地采集物的出现权重；雪山和高起伏地提高裸岩、金属节点和遗迹入口权重；樱花树林提高森林采集物和景观探索点权重。
- **水文价值**：水面用于采集原水、灌溉和路线判断；河谷提供连续水源和运输方向；沼泽提供更密集但更难接近的水陆资源。水量不会因群系标签自动无限生成，仍遵守现有采集、容器和生产规则。
- **聚落与建筑**：聚落选择同时考虑群系、地貌、可达空地和建筑用途。河谷适合村落、农田和运输节点；草甸适合早期聚落；森林可出现林业和隐蔽建筑；荒漠、雪山和沼泽的建筑应更依赖道路、山口、堤岸或稳定地面。
- **探索节奏**：草甸与河谷负责方向感和补给连贯性；森林负责视野、遮挡和资源搜索；湿地与沼泽负责绕行和地面选择；荒漠负责补水与远征规划；冻原与雪山负责体温、天气、山口和回撤；樱花树林负责低压景观、地标和可选探索目标。
- **敌人与动物**：沿用按群系、分区、昼夜和天气变化的分布框架。新增群系先调整已有生物和敌人权重，不在本文件中承诺新增生物种类；雪山、沼泽和河谷可以通过可见度、地形阻隔和遭遇密度产生差异。
- **探索奖励**：群系改变资源点、建筑蓝图候选、地标密度和路线风险，不把任何单一群系做成唯一主线入口。玩家应能通过多种地形组合完成基础生存和工业推进。

## 后续美术计划

当前图集保留六类基础群系地表，并通过独立 `biomes` 图集接入四类新增群系的专用地表、生态簇、树木和装饰；完整跨群系过渡图块仍未覆盖。美术扩展按以下顺序进行：

1. 先为六类现有群系补齐统一的地面基底、边缘、角点、浅水/湿润地表和可重复拼接规则，解决区块边界与群系边界的视觉断裂。
2. 已完成沼泽、雪山、樱花树林、河谷四类群系的第一版基础地面和关键识别元素接入：沼泽包含泥水、芦苇与湿地树木；雪山包含积雪、裸岩与覆雪针叶树；樱花树林包含花瓣、花树与林地装饰；河谷包含河岸砾石、湿地植被与沿岸树木。
