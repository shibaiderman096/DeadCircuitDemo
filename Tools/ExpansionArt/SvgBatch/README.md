# Current SvgBatch sources and verification

The current authoring set contains **206 frames**. These are code-authored
integer-grid SVGs; this maintenance pass deletes unused cells without drawing
new art or changing retained frame pixels.

| Runtime atlas | Size | Frames |
|---|---:|---:|
| Art/Expansion/icons.png + icons.json | 576 x 216 | 82 |
| Art/Expansion/world.png + world.json | 576 x 288 | 124 |

Sources/*.svg, *.layout.json and *.catalog.json are the current editable source,
packing and label/registration records. Runtime JSON uses top-left rectangles.
Cells retain 32 x 32 content, 36-pixel stride, two-pixel gutters, 32 PPU and
centred pivots (the legacy JSON's omitted registration fields use DemoArt's
32/.5/.5 defaults). Texture and JSON .meta GUIDs are preserved.

## Commands

Use the installed Python 3.12 with Pillow, numpy and resvg_py, always with -B:

~~~powershell
python -B Tools/ExpansionArt/SvgBatch/verify_runtime_atlases.py
python -B Tools/ExpansionArt/SvgBatch/export_and_qc.py
python -B Tools/ExpansionArt/SvgBatch/export_and_qc.py --publish
python -B Tools/ExpansionArt/SvgBatch/export_and_qc.py --publish --review
~~~

The verifier is read-only and checks authoring-code/SVG/PNG equality, exact
source/runtime indexes, labels, nonempty/unique frames, binary alpha, packing,
gutters and actual runtime fallback targets. The exporter defaults to an
in-memory local resvg render and read-only comparison. Only --publish writes
current Sources and the four world/icons runtime files; --review additionally
refreshes current contact sheets. No command writes historical Reports/Renders.

For this retirement, compare against the pre-cleanup Git revision as well:

~~~powershell
python -B Tools/ExpansionArt/SvgBatch/verify_runtime_atlases.py --baseline-ref HEAD
~~~

Use a pre-cleanup ref after committing. This optional check performs read-only
git show calls, requires exactly the 35 approved removals, compares all 206
retained slices byte for byte in RGBA, checks effective PPU/pivots and catalog
registration, and compares .meta content while normalizing checkout CRLF/LF.
It never rewrites metadata to satisfy a check.

## Historical evidence

Reports/main_runtime_verify.json records the current 206-frame check. The other
Reports and Reports/Renders contain retained historical evidence for the older
241-frame (151 world + 90 icons) revision. Their old counts, packing, renderer
versions and hashes describe that revision, not the current 206-frame set.
They are not regenerated by current tooling. Historical visual corrections
changed 37 frames; those corrections are retained in the current authoring.

revise_visual_contracts.py is now a **read-only historical comparison** of the
retained final and visualreview1 renders against their recorded per-frame hashes.
It never generates sources, publishes runtime files or updates reports, and
rejects --publish immediately. Use export_and_qc.py for current authoring.
If historical render files have separately been retired, the historical command
requires those files and is not a replacement for the independent current verifier.

No Unity Editor, Play Mode, gameplay, import or performance validation is claimed
by these Python checks. This pass does not alter audio, gameplay or C#.
